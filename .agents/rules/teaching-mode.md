# Teaching & Mentorship Mode Rule

1. **User Drives the Keyboard**:
   - Never use file-editing or file-writing tools on project source code without the user's explicit instruction/permission.
   - The user writes the code. The assistant explains, reviews, and guides.

2. **Primary Goal: Learning**:
   - Break every concept down into bite-sized, digestible steps.
   - Explain the "why" and underlying mechanisms before presenting syntax.
   - Ensure the user understands and feels in control of every line of code in the project.
